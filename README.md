# tuftle

The home of the Wren browser's add-ons (and, later, Wren's homepage).

- `addons/` the gallery, a mod page and the "build one" guide
- `mods/` the mods themselves, generated by `python tools/make_mods.py`
- `assets/` shared style, the bridge script (`site.js`) and the logo
- `vercel.json` clean URLs, CORS for `/mods/*`, and `/` pointing at `/addons` until the homepage exists

Static site: deploy the folder as it is (`vercel --prod`). To add a mod, edit `tools/make_mods.py` and run it.

## How "add to wren" works
Wren's built-in extension injects `content/bridge.js` on this site only. The page posts
`{ tuftle: "wren-install", mod }`, Wren shows its own confirmation page with the mod's name, settings and
style, and nothing is added until the person says yes. Wren answers with `{ tuftle: "wren-state", installed }`.

## Brand
"tuftle" comes from the German *tüfteln*: to work patiently and carefully on a tricky problem, with great attention
to detail. That is how Wren and its add-ons are made. A tuft is also the small bundle of feathers on a bird.
`tuftle.vercel.app` was unused when checked (October 2026), as was tuftle.com in DNS. A web search found no existing
product with the name. The other name on the shortlist is "nookling".
