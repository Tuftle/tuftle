# tuftle brand

**Mark:** five soft, round-tipped feathers fanned from one point, like a plume. The tall middle feather is cream on brown (brown on cream) and the others amber, with a thin gap between them so it still reads at 16px.
**Name:** from the German *tüfteln*, to work patiently and carefully on a tricky problem. **Tagline:** small things, made patiently.
**Type:** Georgia, lowercase. The lettering in the logo files is outlined, so no font is needed.
