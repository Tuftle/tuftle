build a mod for wren

a mod is a single json file. wren reads it, shows the person exactly what it does, and applies the css to the browser window. that is all there is to it. you do not need to build anything or learn a new language.

the smallest mod

{
  "format": 1,
  "id": "rounder-urlbar",
  "name": "rounder address bar",
  "version": "1.0.0",
  "author": "you",
  "description": "makes the address bar a pill.",
  "css": "#urlbar-background { border-radius: 999px !important; }"
}

the fields

fieldwhat it is
formatalways 1 for now.
idlowercase letters, numbers and dashes, 2 to 41 characters. it is the mod's name to wren, so keep it unique.
name, descriptionshown to the person before they add it. keep them plain and honest.
version, authorfree text. bump the version when you change the file.
cssthe style for the browser window itself, up to 200 kb. see the notes below.
prefsoptional settings to turn on while the mod is on. only the ones in the list below are allowed.

what the css can touch

your css is added to every wren window, the toolbars, the tab list and the address bar, not to web pages. the usual places to start are #nav-bar, #urlbar-background, #urlbar[focused="true"], .tab-background, #sidebar-main and toolbarbutton. wren is built on firefox, so any firefox userChrome guide applies. add !important when something refuses to change.

for safety, wren removes @import and any url() that points at the web. images must be inlined as data: urls. a mod can restyle the window, but it cannot load anything from the internet.

settings a mod may set

when the mod is turned off or removed, wren puts these back how they were.

settingvalues
browser.uidensity0 normal, 1 compact, 2 touch
browser.compactmode.showtrue or false
browser.tabs.hoverPreview.enabledtrue or false
browser.toolbars.bookmarks.visibility"always", "never" or "newtab"
browser.download.autohideButtontrue or false
sidebar.verticalTabs, sidebar.position_starttrue or false
wren.mod.<your-id>.*anything you like, under your own name, for your own use.

try it

  1. open the mods page in wren: press Alt+Shift+K and type mods.
  2. paste your json, or choose the file, and press check it.
  3. wren shows the name, the settings and the css. press add mod.
  4. change the file and add it again. the new version replaces the old one.

share it

host the json file anywhere and send the link, or let someone download it and add it from the mods page. a place to submit mods to this site is coming. until then, tell people what it does and show a picture.

what is coming

mods that move things around, small scripts that you opt into one by one, and a way to publish your own. wren also runs ordinary firefox extensions from the extension shelf, so a mod can sit next to the tools you already use.
