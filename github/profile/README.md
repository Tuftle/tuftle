# tuftle

small, quiet software, made with patience.

the name comes from the german word *tüfteln*: working on a tricky problem slowly and carefully until it is right.

## what is here

- **wren** is a browser built on firefox. it is cream and brown, it has no accounts, and nothing is sent home on its own. it is not released yet.
- **nook** is a search engine with no accounts and no logs. it can also answer simple questions right in the address bar. [nooksearch.vercel.app](https://nooksearch.vercel.app)
- **wren add-ons** are small files that change how wren looks. anyone can write one, and wren shows you what a mod does before you add it. [tuftle.vercel.app/wren/addons](https://tuftle.vercel.app/wren/addons)

## how things are made

- nothing follows you. no accounts, no tracking.
- calm over busy. fewer buttons, gentler colours.
- you can change it. if something bothers you, there should be a way to fix it.
